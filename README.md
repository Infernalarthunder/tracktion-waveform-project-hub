| **Feature** | **Description** |
|:---|:---|
| **Project Library** | Organize Waveform projects with genre tags and BPM |
| **Plugin Tracker** | Track installed plugins with preset count and favorites |
| **Template Manager** | Save and manage project templates per music style |
| **Session Archive** | Archive completed sessions with export format notes |
